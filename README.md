# 🧠 LinguaMind AI

**LinguaMind AI** is a full-stack language learning platform designed to help users improve their language skills through vocabulary practice, personalized learning, progress tracking, and AI-powered assistance.

> 🚧 **Project Status:** Currently under development. Core backend, database, authentication, and REST API architecture are being developed. AI integration is planned for the next phase.

## 🚀 Features

* 🔐 User Registration & Login
* 🔑 JWT-based Authentication & Authorization
* 📚 Vocabulary Management
* 📈 Learning Progress Tracking
* 🔥 Learning Streak Tracking
* 🌐 RESTful API
* 🗄️ MySQL Database Integration
* 🤖 Planned AI Language Tutor
* ✍️ Planned Intelligent Mistake Correction
* 📖 Planned AI-generated Learning Stories
* 🎯 Planned Personalized Learning Assistance

## 🔐 Security

LinguaMind AI uses **Spring Security and JWT** for authentication and authorization.

Sensitive credentials and API keys should be stored securely on the backend and should **never be exposed in the frontend or committed to GitHub**.

## 🤖 AI Integration

The AI component is currently under development.

Planned AI capabilities include:

* AI-powered language tutoring
* AI-generated learning stories
* Intelligent mistake correction
* Personalized learning recommendations

AI API credentials will be kept securely on the server rather than exposed to the frontend.
